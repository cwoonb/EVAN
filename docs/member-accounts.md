# 임시 회원 계정과 AI 질문 한도

기존 Next.js 정적 사이트와 별도 FastAPI 게이트웨이를 유지합니다. Supabase는 실제 연결된 프로젝트가 없으므로 새 외부 서비스를 요구하지 않고 같은 게이트웨이에 회원 DB와 댓글을 연결합니다. 기존 Supabase SQL·클라이언트와 공유 코드 인증 구현은 보존하지만 회원 모드에서는 사용하지 않습니다. 뉴스 수집·LAYA·Qwen·CSV·공개 JSON은 수정하지 않습니다.

## 운영 설정

서버 전용 `server/.env`에 다음 설정을 추가합니다. 경로는 사용자 소유의 비공개 디렉터리여야 합니다.

```dotenv
MEMBER_AUTH_DB=/absolute/private/path/server/.state/members.sqlite3
```

`scripts/run_ai_service.py`의 기존 검사·시작·재시작 명령을 그대로 사용합니다. 이 설정이 있으면 회원 인증이 공유 코드·Supabase 인증보다 우선합니다. 이전 공유 코드는 회원용 AI 권한을 부여하지 않습니다. 정적 사이트에는 기존 `NEXT_PUBLIC_EVAN_API_URL`만 필요하며 회원 비밀키나 DB 경로는 넣지 않습니다.

회원 DB는 SQLite이며 디렉터리 0700, DB 0600, 비밀번호 scrypt(N=2^17, r=8, p=1)와 계정별 무작위 salt를 사용합니다. 세션은 8시간 유효한 무작위 bearer 토큰이고 DB에는 토큰의 SHA-256만 보관합니다. 로그아웃은 서버 세션도 폐기합니다. 브라우저는 탭의 sessionStorage에 토큰·만료 시각·API 원점만 저장하고 이름·생년월일은 메모리에만 보관합니다. 프로필과 인증 응답은 캐시하지 않습니다. HTTPS 주소가 바뀌면 다시 로그인해야 하지만 계정과 사용량은 유지됩니다.

아이디는 영문·숫자·밑줄 4–24자이며 대소문자를 구분하지 않습니다. 비밀번호는 15–128자입니다. 임시 가입은 만 14세 이상으로 제한합니다. 이메일·휴대폰 확인과 자동 비밀번호 복구는 제공하지 않습니다. 입력한 이름·생년월일은 본인 확인을 거친 정보가 아니며 공개 댓글에는 아이디만 표시합니다.

비밀번호 정책 참고: [OWASP Password Storage](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html), [NIST SP 800-63B](https://pages.nist.gov/800-63-4/sp800-63b.html).

## 개인정보와 열람 기록

가입 시 계정 관리와 연령 확인 목적의 아이디·이름·생년월일 수집 동의를 받습니다. 나이는 생년월일로 계산하고 별도 컬럼에 저장하지 않습니다. 이름·생년월일은 본인 프로필 API에만 반환합니다. AI 검색 문맥이나 공개 뉴스 JSON·댓글 API·GitHub 저장소에 포함하지 않습니다.

열람 기록은 기본적으로 저장하지 않습니다. 별도의 선택 동의를 한 경우에만 로그인한 계정의 기사 식별자와 마지막 열람 시각을 기록합니다. 관심 뉴스 파악 용도로 최대 90일 보관하며 시작 시·시간마다·관련 요청 시 만료 기록을 삭제합니다. 서버가 꺼져 있는 동안은 삭제 작업도 중단되며 다시 켜지면 정리합니다. 동일 기사를 다시 보면 마지막 시각만 갱신합니다. 내 계정에서 동의 철회 시 기존 기록을 지우며, 기록만 비우기도 가능합니다. 비로그인 열람은 추적하지 않습니다. 회원 정보·열람 기록을 열람하는 공개 관리자 API는 없습니다.

탈퇴에는 비밀번호 재확인과 별도 확인 화면이 필요합니다. 계정·세션·열람 기록·사용량·신고를 삭제하고 작성한 댓글의 본문을 비웁니다. 답글 연결을 보존하기 위해 내용이 없는 삭제 댓글 자리만 남깁니다. 운영자는 비공개 DB의 OS 접근과 백업도 보호해야 합니다. 현재 새 외부 분석 도구나 공개 개인별 통계는 도입하지 않습니다.

## AI 한도

로그인한 **계정마다 한국 시간 자정부터 다음 자정까지 10회**입니다. 한국 날짜와 초기화 시각을 서버에서 계산합니다. SQLite 트랜잭션으로 요청을 예약하므로 여러 탭·동시 요청·프로세스 재시작으로 한도가 초기화되지 않습니다. 정상 답변에는 근거를 찾지 못했다는 정상 안내도 포함됩니다. 잘못된 요청, 없는 기사, 서버 혼잡과 모델 오류는 일일 횟수를 차감하지 않습니다. 실패 예약은 환불하고, 작업자가 비정상 종료한 미완료 예약은 10분 후 만료합니다. 취소 시 서버에서 이미 답변을 완료한 요청은 차감될 수 있습니다.

분당 6회와 로그인·가입·댓글·신고 요청 제한을 별도로 둡니다. 기존 `CHAT_REQUESTS_PER_DAY=100`은 게이트웨이의 추가 보호 제한이며 회원 일일 10회 정책을 대신하지 않습니다. 아이디를 새로 만드는 것까지 동일한 실제 사람으로 검증하지는 않습니다. 가입은 IP와 전역 횟수로 제한하며 DB에는 원본 IP 대신 HMAC 식별자만 저장합니다.

## 댓글

공개 목록은 비로그인으로 읽습니다. 작성·답글·본인 댓글 수정·삭제·신고에는 같은 회원 세션이 필요합니다. 서버가 소유권·실제 기사·답글의 기사 일치 여부를 확인합니다. 댓글 1–2,000자, 과도한 링크·HTML·반복 스팸 제한을 적용하고 React 텍스트로 표시합니다. 세 계정의 신고가 누적되면 임시 숨김 처리합니다. 이는 완전한 욕설 탐지나 운영자 검토 시스템을 대신하지 않습니다. 신고는 비공개로 보관하며 뉴스와 AI의 근거로 사용하지 않습니다.

## API

- `POST /v1/members/signup`, `/login`: 가입·로그인과 세션, 본인 프로필, 일일 한도 반환
- `GET /v1/members/me`, `POST /v1/members/logout`: 본인 세션과 사용량 조회·종료
- `POST /v1/members/privacy`: 선택 동의 변경
- `GET|POST /v1/members/history`, `POST /v1/members/history/clear`: 본인 기록 조회·저장·비우기
- `POST /v1/members/delete`: 비밀번호 재확인 후 탈퇴
- `GET|POST /v1/comments`, `POST /v1/comments/{id}/edit|delete|report`: 댓글 읽기와 인증된 변경
- `POST /v1/chat`: 회원 토큰과 기존 뉴스 질문 계약, 성공 시 `quota` 추가 반환

미로그인 사용 시 ‘먼저 로그인을 해주세요’ 팝업과 로그인 링크를 제공합니다. 로그인 서버나 Mac이 꺼졌다면 회원 기능·댓글 API·AI 연결 실패를 안내하며 정적 뉴스와 관련 기사 탐색은 계속 가능합니다. 임시 HTTPS 터널과 기존 단일 Mac 서버의 가용성 한계는 유지됩니다.

npm run lint

npm run test:ai
GITHUB_PAGES=true NEXT_PUBLIC_BASE_PATH=/EVAN npm run build

회원 회귀 검증은 비밀번호·토큰 저장, 재시작·만료·로그아웃, 한국 시간 자정, 10번째 허용·11번째 거절, 동시 예약, 오류 환불, 댓글 소유권·답글·신고·삭제, 선택 동의·보관 기간·회원 간 격리를 검사합니다. 테스트 DB와 계정은 임시 디렉터리에 만들고 실제 회원이나 뉴스 파일을 초기화하지 않습니다.
