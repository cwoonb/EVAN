# 뉴스 홈 개편과 배포 검증

## 변경 범위

기존 Next.js App Router 사이트와 GitHub Pages `/EVAN/` 배포를 유지합니다. 뉴스 수집기, Qwen/LAYA 설정, 중요도 분석, CSV와 공개 JSON 생성 방식은 수정하지 않습니다.

- `components/NewsSection.tsx`, `app/news/briefing.css`: 선택 날짜·검색·키워드의 전체 결과를 먼저 구한 뒤 5·4·3등급으로 나눕니다. 5등급 대표 1건과 나머지 모든 기사의 제목·저장된 핵심 요약을 기본으로 펼쳐 표시합니다. 4등급은 중간 카드 6건, 3등급은 간결한 목록 12건과 정확한 등급의 전체 보기로 연결합니다.
- `components/NewsExplorer.tsx`, `app/news/news.css`: 날짜와 정확한 등급 필터를 추가합니다. 1·2등급, 기존 최소 등급 필터, 최신순·중요도순, 페이지 이동은 전체 탐색에 유지합니다. 홈은 등급별 최신순으로 고정합니다.
- `lib/news-layout.ts`: 원본을 변경하지 않는 중요도 정규화, 한국 날짜, 검색·정렬·그룹, 필터 링크를 관리합니다. [데이터 계약](news-layout-data.md)을 참고하세요.
- `components/NewsImage.tsx`, `lib/news-images.ts`, `app/news/news-image.css`: 기사 이미지 승인 정책과 안정적인 카테고리 이미지 선택, 로딩 실패 처리를 공유합니다. 이미지 영역의 비율을 미리 확보하며 대표 카드만 preload하고 나머지는 lazy loading합니다.
- `components/NewsArticleDetail.tsx`, `lib/related-news.ts`: 관련 기사로 연속 이동한 뒤에도 원래 목록의 날짜·등급·검색·키워드·정렬을 보존합니다. 외부 원문 URL은 바꾸지 않습니다.
- `types/news.ts`: 향후 사용 가능한 선택적 `image` 필드만 추가합니다. 기존 데이터 파일에 이 필드를 쓰거나 원문을 공개하지 않습니다.
- `.github/workflows/deploy.yml`, `package.json`, `tests/news-layout.test.mjs`, `tests/news-images.test.mjs`: 새로운 UI 계약 검증을 기존 배포 검사에 추가합니다.

기존 기사 상세, 관련 보도, 출처 링크, AI 대화, 댓글 연결 상태, 리서치 화면은 유지합니다. 실제 일일·키워드 보고서 데이터가 없으므로 새로운 보고서나 숫자를 생성하지 않습니다.

## 이미지 운영

실제 기사 사진은 URL만으로 사용하지 않습니다. `lib/news-images.ts`의 명시적 승인 목록에 사용 권한과 승인 시각이 있어야 표시합니다. 현재 승인된 기사 사진은 없으며 로컬 분류 이미지로 운영합니다.

실패 순서는 승인된 기사 이미지, 카테고리 이미지, 공통 이미지, CSS 배경입니다. 실패한 주소는 현재 브라우저 세션에서 기억하여 다른 카드에서도 반복 요청하지 않습니다. 이미지 실패는 기사 제목·요약·링크를 제거하지 않습니다.

자산은 `public/images/news-fallbacks/`에 있습니다. 카테고리별 3장과 공통 1장입니다. 파일명과 별칭은 `categoryImageManifest`, `normalizeCategory`가 한곳에서 관리합니다. ID, 원문 URL, 안정적인 제목·발행 시각 순서로 식별하여 같은 매핑 버전에서는 정렬·필터·새 기사 추가와 관계없이 같은 변형을 선택합니다. 배경은 실제 사건 사진이 아니며 ‘분류 이미지’로 표시합니다.

자산별 생성 출처와 크기, 교체 절차는 [이미지 운영 문서](news-images.md)를 참고하세요. 브라우저에서 LLM·이미지 생성 요청을 하지 않습니다.

## 실행과 검증 명령

```sh
npm ci
npm run dev
npm run lint
npm run typecheck
npm run test:layout
npm run test:briefing
npm run test:images
npm run test:related
npm run test:presentation
npm run test:ai
npm run test:comments
server/.venv/bin/python -m unittest discover -s tests -p 'test_*.py'
GITHUB_PAGES=true NEXT_PUBLIC_BASE_PATH=/EVAN npm run build
```

Python 테스트는 `server/requirements.txt`를 설치한 환경을 사용합니다. 운영 API 주소와 Supabase 공개 설정은 기존 환경 변수와 GitHub Actions 저장소 변수로 유지합니다. 비밀키나 접속 코드를 공개 저장소에 추가하지 않습니다. 개발 서버가 실행 중이면 별도 임시 복사본에서 production build하여 `.next` 충돌을 피합니다.

## 연결 제한

댓글은 기존 Supabase 설정이 없어 ‘연결 준비 중’으로 안내합니다. AI는 기존 HTTPS 게이트웨이와 접속 코드 인증을 사용합니다. 새로운 회원가입·알림·챗봇·보고서 기능은 추가하지 않습니다.

## 2026-10-23 5등급 가독성 보정

대표를 제외한 5등급 뉴스가 제목과 출처만 표시되어, 요약이 있는 4등급 카드보다 정보가 적게 보이던 문제를 수정했습니다. 모든 5등급 기사에 기존 요약을 최대 두 문장으로 기본 표시합니다. 제목·요약은 줄 수로 잘라 숨기지 않으며 별도 펼치기나 페이지 이동이 필요하지 않습니다. 새 요약 생성이나 원본 데이터 변경은 없습니다. 별도 요약이 없거나 제목과 중복되는 내용뿐이면 내용을 만들어 채우지 않습니다.

나머지 5등급은 넓은 두 열의 카드로 표시하고 900px 이하는 한 열로 배치합니다. 제목은 데스크톱 22px·모바일 20px, 요약은 16px와 줄간격 1.75를 사용합니다. 4등급 제목 18px·본문 14px, 3등급의 간결한 목록보다 5등급의 정보와 시각적 강조가 우선합니다. 모바일 대표 카드는 제목·요약을 이미지보다 먼저 표시하여 핵심 내용을 빠르게 읽을 수 있습니다.

`tests/news-briefing.test.mjs`는 실제 `NewsSection` 컴포넌트를 렌더링하여 여러 5등급 요약의 노출, 대표 중복 제거, 다른 날짜·등급의 기사 대체 금지, 빈 요약 및 중복 문장 처리를 검증합니다. 이 검증은 GitHub Pages 배포에도 포함됩니다.

보정 검증: 실제 공개 뉴스에서 2026-10-20의 5등급 6건과 2026-10-19의 15건 모두 제목과 요약이 표시됩니다. 검색 후에도 해당 요약과 날짜·검색 조건을 담은 상세 링크가 유지됩니다. 390px·430px·768px·1440px에서 가로 넘침 없이 렌더링되며, 5등급 본문은 16px·28px 줄간격으로 잘림 없이 보입니다. 새 컴포넌트 회귀 6개와 기존 관련 UI 검증이 통과했고, Pages 모드 19페이지 빌드도 성공했습니다.

## 2026-10-24 전체 뉴스 탐색 목록

전체 탐색의 큰 이미지 카드 그리드를 작은 왼쪽 썸네일과 기사 정보가 나란히 놓이는 목록으로 변경했습니다. 제목, 최대 세 개의 키워드, 대표 원문의 언론사·발행 시각, 중요도를 표시합니다. 여러 원문이 있는 이슈만 원문 개수를 덧붙입니다. 행 전체를 누르면 기존 기사 상세 화면으로 이동합니다.

한 페이지에 24개를 표시합니다. 목록 제목은 최대 두 줄, 키워드는 한 줄로 제한하고 긴 요약은 상세 화면에서 읽도록 합니다. 원본 제목·요약·CSV·JSON은 바꾸지 않습니다. 전체 제목은 링크 안에 보존하고 제목 툴팁과 상세 화면에서 확인할 수 있습니다. 홈의 5등급 뉴스 제목과 핵심 요약은 기존대로 모두 표시합니다.

실제 브라우저에서 390px·430px·768px·1440px의 가로 넘침이 없음을 확인했습니다. 모바일 썸네일 영역은 76px, 제목은 16px이며 출처·시각은 줄바꿈합니다. 페이지 이동(1–24, 25–48), 날짜·중요도·검색·정렬 조합, 빈 검색 결과, 상세 이동 후 검색 조건 보존, 키보드 포커스를 확인했습니다. lint·TypeScript와 관련 UI 검증 47개가 통과했고, GitHub Pages `/EVAN/` 모드의 정적 19페이지 production build가 성공했습니다.
